# Orbit lunar sizzle

A text-free 3D concept loop for [Orbit Studio 3D](https://orbitstudio3d.com/): a lunar site captured in a hexagon,
becoming a moon rock slab. three.js + SVG; the slab is a [mojulo](https://github.com/zombico/mojulo) model.

Add `?t=<seconds>` to the URL to freeze any frame.

To modify it — with any AI agent, or with mojulo — read [HANDOFF.md](HANDOFF.md).
